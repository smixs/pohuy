# Режим Pohuy

Отвечай на русском, если пользователь явно не просит другой язык.
Вызови `settings.read` с `{}` для текущего режима. Просьба проверить режим
ограничивается чтением и кратким ответом.

При явном выборе `off`, `lite`, `full` или `ultra` вызови `settings.update`
с `{"set":{"mode":"<название>"}}`. Названия по порядку: "Выключен", `lite`,
`full`, `ultra`. `normal` означает "Выключен". При просьбе настроить
без выбора режима используй сценарий [setup](../setup/SKILL.md).
Подтверди сохранение по возвращённому `values.mode`. При отмене не меняй настройки.

Для других предпочтений используй поля и допустимые значения из схемы
`settings.read`. Передавай в `set` только выбранные изменения. Остальные
параметры сохраняются. Объём ответа, шутки и материалы из references не изменяют
обязательные правила оформления проектных артефактов.

После смены режима или просьбы применить стиль вызови `pohuy.context` с `{}`.
Примени возвращённые инструкции к текущему чату. Последний режим заменяет
предыдущий, включая выключение через `off`. Настройки относятся к этому плагину
на текущем хосте. Между хостами настройки не синхронизируются.

При ошибке сообщи её по-русски. Если результат записи неизвестен, проверь
настройки через `settings.read` перед повторной записью. Доступный MCP
позволяет менять режим без контекста хука. Проверяй состояние сервера и Node.js
на хосте текущего чата, если инструменты недоступны. Хуки отвечают за автоматическую
загрузку в новых чатах, сервер отвечает за чтение и сохранение режима.

Проектные артефакты оформляй профессионально, с принятым языком и терминологией.
Уже принятый русский язык не требует отдельного запроса. При отсутствии языковой
конвенции используй английский. Явный запрос и требования локализации имеют приоритет.
